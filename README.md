# CLI-Monitor
Simple CLI for monitoring your system stats, packets, and whats going on under the hood! You can also plug in your openai api keys to chat with ai directly about what you are viewing!

# How to run
git clone https://github.com/FelixL1234/CLI-Monitoring.git
cd CLI-Monitoring
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
export OPENAI_API_KEY="your_key_here"
